# JEPA-model-for-image-generation

This project explores the principles behind Joint Embedding Predictive Architectures (JEPA) through a from-scratch implementation using TensorFlow/Keras.

The objective is to build a small Vision Transformer-based architecture capable of learning meaningful image representations and predicting the representation of masked regions in the latent space, rather than directly reconstructing their pixels.

The project focuses on understanding and implementing the fundamental components involved in modern representation learning: image masking, patch embeddings, self-attention, Vision Transformers, latent representations, and embedding-space prediction.
